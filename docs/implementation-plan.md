## De ce am ales aceste tehnologii

| Tehnologie | De ce am ales-o |
|---|---|
| **Java 21 + Spring Boot 3 + Maven** | Spring Boot vine cu tot ce ne trebuie pentru un API: securitate, validare și acces la baza de date |
| **MySQL 8** | Datele noastre sunt legate între ele: utilizatori, echipamente, atribuiri. Baza de date relațională ne ajută direct, de exemplu nu acceptă două echipamente cu aceeași serie. |
| **Spring Data JPA** | Ne scuteste de scrierea query-urilor SQL manual + usor de modificat daca se alege alta baza de date|
| **React + Vite ** | React ne lasă să refolosim componentele, Vite este rapid |
| **Docker Compose** | Avem aceeasi versiune de baza de date MySQL pentru orice device separat|
